About This Project

Mission

This system provides flood risk assessment for four Metro Manila cities (Manila, Marikina, Pasig, and Quezon City) using historical weather data and machine learning. It is an academic capstone project — not an official flood warning service.

How It Works

The system uses two machine learning models trained on five years of daily weather and flood records (2016–2020):

  • Regression model (CART Decision Tree): predicts the expected flood depth in meters given current conditions.
  • Classification model (CART Decision Tree): predicts the risk level (Low, Moderate, High) based on MGB flood susceptibility thresholds.

Both models take the same inputs: rainfall, river water level, soil moisture, elevation, and city location (one-hot encoded).

Why Decision Trees?

Flood relationships are non-linear and threshold-driven (e.g., a small increase in rainfall past a certain point triggers disproportionately more flooding). Decision trees handle this naturally. They also handle multicollinearity between the four predictors better than linear models, and produce interpretable decision rules that can be visualized.

Data Sources

  • Historical weather & flood data (2016–2020): Kaggle — "Metro Manila Flood Prediction"
  • Live weather: Open-Meteo (rainfall, forecasts)
  • Flood susceptibility thresholds: Mines and Geosciences Bureau (MGB)
  • Flood event reports: LGU archives, news archives (self-compiled)
  • Evacuation centers & hotlines: LGU-published resources (self-compiled)

Technology

  • Python (pandas, scikit-learn, Flask)
  • SQLite for local data storage
  • Leaflet.js for interactive maps
  • Chart.js and matplotlib for visualizations
  • Bootstrap 5 for responsive layout

Limitations

This is a research tool. Please be aware of the following limitations before interpreting its predictions:

  • Coverage: only 4 of 16 Metro Manila cities are covered, due to data availability.
  • Flood depth estimates: historical flood depths were compiled from news and LGU reports (descriptive language converted to meters via a documented reference table), not sensor measurements.
  • River water level: no reliable public API exists for real-time river gauges. The system uses a monthly seasonal average per city as a proxy, and clearly labels this in the interface.
  • Soil moisture: the training data's soil moisture scale is source-specific and incompatible with Open-Meteo's m³/m³ units, so a monthly seasonal average is used as a proxy.
  • Rainfall timing: today's rainfall value is a calendar-day total (00:00–23:59) that blends observed rainfall with forecast rainfall for the rest of the day — it is not a rolling 24-hour total.
  • Confidence scores: the classifier's confidence (e.g., "82% High") reflects certainty in the classification, not flood occurrence probability. Dry days (~98% of records) often produce 100% confidence because the training set is heavily class-imbalanced.
  • Admin boundaries: city polygons are official administrative boundaries, which for coastal cities (Manila) extend into Manila Bay.

Disclaimer

Not for emergency use. This system is intended for academic research and demonstration only. For real flood warnings and evacuation instructions, always follow PAGASA, NDRRMC, and your local government unit.
